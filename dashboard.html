About SAT-SA
Architecture & compliance information

SAT-SA is an air-gapped, offline-first supervisory analytics platform built for NCIIPC / NTRO auditors to assess Critical Sector Entities' (CSEs') SOC performance and integrity.


ComponentTechnologyRole
BackendFastAPI + Python 3.11Analytics API server
Analytics DBDuckDB (embedded OLAP)Vectorised SQL engine, no daemon
Execution-Gap Enginescipy · sklearn · numpyZ-score MTTR + TF-IDF cosine sim
Negative-Space Enginenumpy · Poisson baselineTelemetry blackout + zero-alert detection
Graph EngineNetworkXMulti-stage attack chain audit
Local LLMOllama / llama.cpp GGUFOffline AI explainability (Step 4)
FrontendReact 18 + RechartsSupervisor dashboard
DeploymentDocker ComposeAir-gapped container stack

🔴 Air-Gap Compliance: All LLMs, embeddings, vector stores, and databases run locally. No cloud SaaS, no external APIs at runtime.
📋 Scope: SAT-SA is a SupTech tool — batch supervisory audit of historical logs. NOT a SIEM or real-time threat hunter.
✓ Traceability: Every risk score displays exact log IDs, timestamps, and the mathematical rule triggered.
